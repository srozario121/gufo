## 185.4. Re-port the vocab-trim series (and, later, DFlash2) onto ai-sdlc/<frozen tag>

Filed 2026-11-12 from the deployment's item 185 (private evidence, ai-sdlc item 185, decision D1). **Unrefined:**
run plan-review on it before any work.

**Why.** The deployment moves its served gufo from `ai-sdlc/v0.28.1` to the newest upstream release at the
fork-branch cut, frozen there (v0.34.0 or later), on an **empty** patch branch `ai-sdlc/<frozen tag>`. None of
the v0.28.1 series is served:

- #876 is upstream as `2e6aa96c` (v0.29.0);
- the vocab trim is default off, and its served trim set has been empty since 2026-11-09;
- no client sends `logit_bias`.

After the move, configuration G (the trimmed head) runs only on the v0.28.1 image. This item makes G reachable
on the new base. The deployment's move does not need it.

**What to port.** On `ai-sdlc/v0.28.1`:

- `00000e64` (draft-head prefix/set options);
- `a3e3b422` … `cc980e30`, `c539cc13`, `c29cdc14` (trimmed head, fallback tiers, counters, tests; all
  default off).

`9a9f0e8d` (`logit_bias` token IDs, default-off non-ASCII soft suppression) is ported only if a client needs
it. Stock v0.34.0 still rejects a non-empty `logit_bias`.

**Known conflicts.**

- `git merge-tree v0.34.0 ai-sdlc/v0.28.1` conflicts in 17 files: `serve.cpp`, `inference_backend.{cpp,hpp}`,
  `text_generation_backend.hpp`, `text_model_runner.hpp`, `text_sampling_defaults.hpp`, Flash-Next
  `engine.{cpp,hpp}`, `kernels/rocm/{batch,device_model,executor}.cpp`, `executor.hpp`, `kernels.hpp`, its test
  CMakeLists, `cmake/Checks.cmake`, README and QUALITY.md.
- Upstream moved `draft_vocab.hpp` to `src/families/qwen/draft_vocab/` and reshaped it (#988).

**Later: DFlash2.** `ai-sdlc/dflash2-flash-next` (19 commits on `ai-sdlc/v0.28.1`, 22 conflicting files
against v0.34.0) overlaps upstream #988's shared prefix-plus-table head (`bd8fddbf`/`28cfca10`). Port it after
the trim, or retire it in favour of upstream's head.

**Done when.** The series is replayed on `ai-sdlc/<frozen tag>` (or a branch on it), with:

- the fork's tests green;
- the flags-off build byte-identical to the unpatched build on the fixed greedy prompt set (tier 1);
- the deployment told it can serve G again (it gates any adoption with its own quality bar).
